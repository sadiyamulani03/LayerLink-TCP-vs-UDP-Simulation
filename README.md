# 🚀 LayerLink: OSI Simulation with TCP vs UDP

This project demonstrates how data flows across OSI layers and compares TCP vs UDP communication using Python socket programming.

## 🔹 Features
- OSI Layer Simulation (Sender → Receiver)
- TCP Communication (Reliable)
- UDP Communication (Fast but Unreliable)
- Encryption & Decryption (Basic)

## 🧠 Concepts Covered
- Socket Programming
- Networking Protocols
- TCP vs UDP Differences
- Data Encapsulation

## ⚙️ How to Run

### TCP
1. Run receiver:
  python tcp_receiver.py

2. Run sender:
  python tcp_sender.py


### UDP
1. Run receiver:
  python udp_receiver.py

2. Run sender:
  python udp_sender.py


## 📌 Output
Shows how data travels through layers and highlights TCP vs UDP behavior.

Built as part of Computer Networking & Cryptography Practice.
